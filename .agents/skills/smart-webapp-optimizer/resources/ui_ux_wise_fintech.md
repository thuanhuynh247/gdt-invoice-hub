# Wise Fintech UI/UX Design System

Bộ quy chuẩn thiết kế giao diện theo tiêu chuẩn Wise Fintech Pro Max.

## 1. Triết lý Thiết kế (Design Principles)
- **Vibrant & Dark Mode First**: Sử dụng nền tối sang trọng (`bg-slate-950`, `bg-gray-900`) kết hợp với hiệu ứng chuyển màu dải sáng (Gradients).
- **Glassmorphism**: Sử dụng các lớp phủ thủy tinh mờ (`backdrop-blur-md`, `bg-slate-900/80`, `border-gray-800/80`).
- **Bento Grid Layout**: Bố trí thẻ KPI và biểu đồ theo dạng lưới Bento hiện đại, nhất quán về khoảng cách (gap-4, gap-6).
- **Modern Typography**: Sử dụng bộ font chữ sans-serif hiện đại (Outfit, Inter) cho văn bản và font đơn cách (JetBrains Mono, Fira Code) cho dữ liệu số liệu.

## 2. Palette Màu Sắc (Color Tokens)

| Loại Element | Màu HSL / Tailwind | Mục đích sử dụng |
| :--- | :--- | :--- |
| **Primary Accent** | `amber-500` / `amber-400` | Nút nhấn chính, chỉ số KPI quan trọng, viền active |
| **Success Status** | `emerald-500` / `emerald-400` | Trạng thái ĐẠT, tăng trưởng tích cực, phân xưởng PX2 |
| **Info / Workshop 1** | `blue-500` / `cyan-400` | Trạng thái thông tin, phân xưởng PX1 |
| **Warning / Alert** | `rose-500` / `rose-400` | Trạng thái K.ĐẠT, cảnh báo đứt sợi, lỗi Classimat |
| **Surface Panel** | `gray-900/90`, `border-gray-800` | Thẻ Glass Panel, bảng dữ liệu |

## 3. Micro-Animations & Effects
- Bo góc thẻ: `rounded-2xl` hoặc `rounded-xl`.
- Hiệu ứng Hover: `hover:border-amber-500/40 transition-all duration-200`.
- Hiệu ứng Animate: Pulse nhẹ cho cảnh báo lỗi (`animate-pulse`), hiệu ứng mờ dần khi chuyển tab (`animate-in fade-in`).
