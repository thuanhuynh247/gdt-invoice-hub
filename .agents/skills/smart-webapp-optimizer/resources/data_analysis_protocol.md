# Smart Data Analysis Protocol

Quy trình chuẩn hóa bóc tách và phân tích dữ liệu đa định dạng cho `smart-webapp-optimizer`.

## 1. Định dạng File Hỗ trợ
- Excel: `.xlsx`, `.xls`, `.xlsm` (Tích hợp skill `xlsx` cho công thức & openpyxl)
- Structured Data: `.csv`, `.tsv`, `.parquet`, `.avro` (Tích hợp skill `read-file` & `query`)
- Databases: `.duckdb`, `.sqlite`, `.db` (Tích hợp skill `query` DuckDB SQL)
- Documents & Logs: `.json`, `.jsonl`, `.ndjson` (Tích hợp skill `read-memories`)
- Remote URLs: `https://`, `s3://`, `gs://`, `azure://` (Tích hợp skill `read-file`)

## 2. Các Skill & CLI Tool Khảo sát Dữ liệu

### A. Skill `read-file` (DuckDB Data Reader Macro)
Dùng cho mọi file dữ liệu hoặc URL để tự động nhận diện schema, đếm tổng số dòng và xem 20 dòng preview:
```bash
# Đọc file local hoặc remote URL
read-file <path_to_file_or_url> [câu hỏi khảo sát]
```

### B. Skill `query` (DuckDB SQL Query Engine)
Dùng khi cần thực thi câu lệnh SQL nâng cao trực tiếp trên file (Ad-hoc Mode) hoặc cơ sở dữ liệu DuckDB:
```bash
# Ad-hoc query trực tiếp file
query "SELECT workshop, SUM(output_kg) FROM 'data.csv' GROUP BY ALL"
```

### C. Skill `xlsx` (Excel Specialist)
Dùng khi làm việc với file Excel có công thức phức tạp, định dạng cell, hoặc cần kiểm tra recalculate bằng LibreOffice:
```bash
# Kiểm tra recalculate công thức Excel
python scripts/recalc.py output.xlsx
```

### D. Skill `read-memories` (Session Log & Decisions Recall)
Dùng để tra cứu lại lịch sử quyết định, quy tắc hoặc lỗi đã giải quyết trong các phiên trước:
```bash
# Tra cứu theo keyword trong log dự án
read-memories "Classimat 4x4" --here
```
